## Vercel

1. Войти в Vercel и импортировать существующий GitHub-репозиторий aidarBARMEN/LnD-Hack, branch main.
2. Framework: Next.js. Root Directory: `./` (package.json находится в корне Git-репозитория).
   Не выбирать вложенный Project/17-49-06-11-2026-2: это локальный путь, не путь внутри Git.
3. Node.js: 24.x; Install: npm ci; Build: npm run build; Output Directory: автоматический Next.js.
4. Переменные окружения для демо не нужны. Не загружать локальный .env.local и DATABASE_URL.
   APP_MODE по умолчанию demo; реальную загрузку документов и AI не включать.
5. Deploy; дождаться Ready и проверить адрес /ru, /kk, /mobile и /ru/pmpk.
6. Пройти: короткая анкета → выдача → профиль → подготовка обращения → план.
   Контроль: Астана/5/kk/речь не показывает Алматы без явного расширения условий.

Vercel/GitHub может запросить разрешение доступа к репозиторию — владелец проверяет и выдаёт
доступ только к нужному репозиторию. Платный тариф для этого этапа не согласовывался.
Публичный URL фиксировать только после успешной публикации, не угадывать домен.

## Ограничения опубликованного демо

Синтетические анкеты и контакты; не вводить настоящие медицинские/личные сведения.
Данные в памяти вкладки, refresh сбрасывает профиль и план. Брони/форум/чаты локальные.
ПМПК — подготовленные примеры с цитатой и подтверждением, реального PDF upload/NLP нет.
Основной путь RU/KK; часть дополнительных экранов прежнего R1 на русском.

## Локально

npm ci → npm run build → npm start. Сервер оставлен на http://127.0.0.1:3000.
Для телефона из интернета нужен успешный deployment; 127.0.0.1 доступен только на этом ПК.
