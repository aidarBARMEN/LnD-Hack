## Сохранённые функции

Главная и основная навигация открывают новый `/search`. Существующий `/catalog`, сравнение, подготовка обращения, бронирование нянь, форум,
задачи и учебный разбор документов работают. Данные и их ID не удалены. В footer сохранена
ссылка в план для legacy-разбора. Старые модули не заменены backend-имитациями.
Новые экраны сначала русские; старая локализация RU/KK остаётся.

## Границы прототипа

Все сведения о людях, стоимости, отзывах, опыте и проверке документов — примеры.
Клиентское состояние очищается при обновлении страницы. Сообщения не отправляются,
профили не публикуются для других пользователей, деньги не списываются. В поле квалификации
сохраняется только имя выбранного учебного файла; содержимое не читается и не загружается.
Подлинность документов не проверяется. Реальные аккаунты, Storage, проверка оплаты,
модерация, серверная авторизация и постоянное хранение относятся к будущему backend-этапу.
Ни диагноз, ни справка не используются для автоматического медицинского назначения или решения
о праве на господдержку. Не вводить настоящие персональные/медицинские сведения в демо.
